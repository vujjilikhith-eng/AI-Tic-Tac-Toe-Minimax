# 🤖 AI Tic-Tac-Toe — Minimax Arena

A web-based Tic-Tac-Toe game using **Minimax** and **Alpha-Beta Pruning**.

## Features

- Human vs AI
- Easy, Medium and Unbeatable modes
- Minimax decision making
- Alpha-Beta pruning
- Nodes explored counter
- Scoreboard
- Responsive UI

## Technologies

- HTML
- CSS
- JavaScript
- Minimax Algorithm
- Alpha-Beta Pruning
- Git & GitHub

## Run locally

Open `index.html` with VS Code Live Server.

## Architecture

Game Board → Game Logic → AI Decision Engine → Minimax + Alpha-Beta → Best Move → Updated Board
